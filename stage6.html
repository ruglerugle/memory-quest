STAGE 6

ポインタ

番地をしまう変数
🎯 ミッション
ポインタが「番地をしまう変数」であることと、& と * の意味を説明できるようになろう。確認クイズに全問正解すれば合格。
未達成
ねこ博士
前のステージで、ヒープから借りると番地が返ってくると話したね。その番地を覚えておく変数をポインタと呼ぶ。pointer は「指し示すもの」という意味だ。
うさ美
番地も数ですよね。だったら、ふつうの整数の変数にしまえばいいのでは？
ねこ博士
中身はたしかに数なんだけれど、C言語では「これは番地で、その先には int が入っている」という情報も一緒に持たせる。そのために、ポインタは int *p; のように、型の後ろに * を付けて宣言する。「int を指すポインタ p」と読む。
int x = 5;　x という4バイトの箱（たとえば番地 0x20）に 5 を入れる int *p = &x;　&x は「x の番地」。p に 0x20 をしまう。「p は x を指している」と言う *p = 10;　*p は「p にしまってある番地の箱」。そこに 10 を書くので、x が 10 になる
うさ美
& は「番地を取り出す」、* は「番地の先へ行く」。逆向きの操作なんですね。だから *(&x) は x そのもの。
ねこ博士
その通り。p に別の変数の番地を入れ直せば、p が指す先も変わる。p そのものは、ただの番地の入れ物なんだ。
うさ美
p の中身は番地なので、p 自体もどこかの番地の箱に入っているんですね。
ねこ博士
そう。ポインタも変数だから、メモリのどこかに置かれる。いまのパソコン（64ビットの CPU）では、番地は8バイトで表すので、ポインタの箱は8バイトだ。指す先が1バイトの文字でも、4バイトの int でも、ポインタ自身は8バイト。
うさ美
ポインタが指す先の型を知っていると、何がいいんですか？
ねこ博士
*p と書いたときに、何バイト読めばいいかが分かる。int なら4バイト、文字なら1バイト。それから、番地の足し算にも使われる。int の配列を指す p に1を足すと、番地は1ではなく4進む。「次の int」を指すようにね。
int a[3]; が番地 0x40 から並んでいるとき：a[0] は 0x40、a[1] は 0x44、a[2] は 0x48 int *p = &a[0]; なら、p + 1 は 0x44（1つ分＝4バイト進む）、*(p + 2) は a[2]
うさ美
配列の a[2] は、「先頭から int 2つ分進んだ箱」という意味だったんですね。
ねこ博士
そう。C言語の配列の添え字は、ポインタの足し算と同じことなんだ。ここで、ヒープとつなげよう。int *nums = malloc(100 * sizeof(int)); と書くと、int 100個分（400バイト）を借りて、その先頭の番地が nums に入る。sizeof(int) は int の大きさ（多くの環境で4）を表す。
うさ美
そうすると nums[0] から nums[99] として使える。番地は nums に入っているから、関数が終わっても、その番地を返せば借りた場所を使い続けられますね。
ねこ博士
そう。ヒープの場所はスタックの板と違って、関数が終わっても消えない。番地さえ覚えていれば、どこからでもたどれる。
うさ美
逆に、番地を忘れてしまったら？
ねこ博士
借りた場所は残っているのに、もうだれもたどれない。返すこともできない。それが次のステージのテーマ、メモリリークだ。
ねこ博士
最後に、STAGE4 の約束を思い出そう。C言語では、関数の引数には値のコピーが渡される。関数の中から、呼んだ側の変数を書き換えるにはどうする？
うさ美
変数の番地を渡せばいい。関数は受け取った番地の先（*p）に書き込めば、呼んだ側の変数そのものが変わります。
ねこ博士
そう。ポインタは「離れた場所にあるものを、番地で指して操作する」ための道具なんだ。強力だけれど、指している先が正しいかどうかは、プログラムを書く人が責任を持たないといけない。C言語のポインタを、実際にコードを1行ずつ動かしながら練習したければ、『C言語ポインタ道場』で続きをやろう。

確認クイズ

Q1. int x = 5; int *p = &x; *p = 10; を実行したあとの x の値は？

正解！ p には x の番地が入っている。*p は「その番地の箱」なので、*p＝10 は x に 10 を書くのと同じ。

Q2. 64ビットの CPU で、char（1バイトの文字）を指すポインタ自身の大きさは？

正解！ ポインタの中身は番地。番地は8バイトで表すので、指す先の型によらず、ポインタは8バイト。

Q3. int（4バイト）の配列を指すポインタ p に 1 を足すと、番地はいくつ進む？

正解！ p＋1 は「次の int」を指す。int は4バイトなので、番地は4進む。a[i] は *(a＋i) と同じ意味。
